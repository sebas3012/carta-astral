# carta-astral

Calculadora de carta astral, proyecto de práctica.

## Descripción

Página web donde el usuario ingresa sus datos de nacimiento para calcular su carta astral:

- Fecha de nacimiento
- Hora de nacimiento
- Ciudad de nacimiento

> **Estado:** en desarrollo. Por ahora está el formulario y los estilos; el botón **Calcular** todavía no realiza el cálculo.
En progreso 20%

## Tecnologías

- HTML
- CSS

## Cómo usarlo

1. Clonar el repositorio:
   ```bash
   git clone <url-del-repositorio>
   ```
2. Abrir `index.html` en el navegador.

No requiere instalación ni dependencias.
